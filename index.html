Proteção dos seus dados

O app salva os dados localmente no aparelho. Reiniciar o celular/tablet, desligar o aparelho ou ficar sem bateria não apaga os dados salvos.

Importante: nenhum armazenamento local deve ser tratado como backup único. Exporte um backup regularmente.

Backup

Exporte um arquivo JSON e guarde-o no Google Drive, OneDrive, computador ou pendrive.

Redefinição

Use somente se quiser apagar os dados deste aparelho. Faça um backup antes.
